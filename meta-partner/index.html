30초 요약

메타 광고를 남에게 맡길 때 계정을 넘기거나 아이디를 알려줄 필요가 없습니다. 내 계정은 그대로 두고, 상대 회사를 파트너로 초대해 권한만 주는 기능이 따로 있습니다. 전체 과정은 세 번의 클릭 묶음이 전부입니다.

STEP 1 · 2
맡기는 쪽이 초대
설정에서 대행사 번호를 입력하고, 어떤 자산을 어디까지 맡길지 체크합니다. 약 5분.
STEP 3
맡는 쪽이 수락
대행사 화면에 요청이 뜨면 수락합니다. 약 2분.
STEP 4
같이 확인
광고를 만들 때 페이지·인스타가 뜨는지 눈으로 봅니다. 약 5분.

이 방식의 핵심 — 소유권은 계속 광고주에게 있습니다. 대행이 끝나면 광고주가 클릭 한 번으로 권한을 회수할 수 있고, 그동안 쌓인 광고 데이터도 광고주 계정에 그대로 남습니다.

용어 5개만 알면 됩니다

메타 화면은 용어 때문에 어렵게 느껴집니다. 실제로는 다섯 개면 충분합니다.

화면에 나오는 말쉽게 말하면
비즈니스 관리자 / 비즈니스 포트폴리오
줄여서 BM		회사의 금고. 페이지·인스타·광고계정·픽셀을 한곳에 모아두는 곳. 여기 안에 들어와 있어야 남에게 권한을 줄 수 있습니다.
자산(Asset)금고 안에 든 물건들. 페이스북 페이지, 인스타 계정, 광고 계정, 픽셀 네 가지가 기본.
파트너내 금고 물건을 일부만 만질 수 있게 허락한 다른 회사. 대행사가 여기에 해당합니다.
광고 계정광고비가 청구되고 캠페인이 만들어지는 계정. 페이스북 개인 계정과 다릅니다.
픽셀 / 데이터세트홈페이지에 심는 측정 장치. 누가 들어와서 무엇을 샀는지 광고가 알 수 있게 해줍니다.

메타는 화면 이름을 자주 바꿉니다. "비즈니스 관리자" = "비즈니스 포트폴리오", "픽셀" = "데이터세트"는 같은 것을 가리키는 옛 이름·새 이름입니다. 둘 중 뭐가 보이든 당황하지 않으셔도 됩니다.

왜 아이디를 주고받으면 안 되나

"그냥 저희 아이디 알려드릴게요"가 제일 빠른 것 같지만, 실제로는 가장 위험한 선택입니다.

파트너 연결 (권장)아이디 공유·계정 양도 (위험)
계정 소유권광고주 그대로흐려지고, 나중에 분쟁
대행 종료 시클릭 한 번으로 권한 해제비밀번호 변경·자산 회수 협상
광고 데이터광고주 계정에 계속 쌓임대행사 계정에 남아 못 가져옴
보안각자 본인 계정으로 로그인메타 정책 위반 → 계정 잠금 위험
사고 났을 때누가 무엇을 했는지 기록에 남음책임 소재 불명

주의 — 하나의 페이스북 계정을 여러 사람이 나눠 쓰면 메타가 이상 접속으로 판단해 계정을 잠급니다. 광고가 돌던 중에 잠기면 그 자리에서 집행이 멈춥니다. 실제로 자주 일어나는 사고입니다.

내 권한이 관리자가 아님🔴 관리자만 권한을 줄 수 있습니다. 회사 안에서 계정을 처음 만든 사람을 찾으세요.

STEP 1파트너 추가 맡기는 쪽

대행사에게 받을 것은 숫자 15자리 하나뿐입니다. HIZ에 맡기시는 경우 아래 번호를 쓰시면 됩니다.

HIZ 비즈니스 ID
244896071103516
1
business.facebook.com 로그인
2
왼쪽 아래 톱니바퀴 ⚙️ → 설정
3
왼쪽 메뉴에서 사용자 펼치기 → 파트너
4
오른쪽 위 [추가] → "파트너 비즈니스에 자산 관리 권한 부여"

파트너 비즈니스 ID 칸에 244896071103516 입력 → [다음]

메뉴 이름이 조금 다르게 보인다면 — 새 화면에서는 파트너 → [파트너 추가], 옛 화면에서는 파트너 → 추가 → 자산 관리 권한 부여로 나옵니다. "파트너"라는 메뉴를 찾아 들어가 상대 회사 ID를 넣는다는 점은 같습니다.

STEP 2자산 4종 권한 주기 맡기는 쪽

ID를 넣으면 무엇을 어디까지 맡길지 고르는 화면이 나옵니다. 광고 대행에는 아래 네 가지면 충분합니다.

자산줄 권한왜 필요한가
광고 계정광고 관리캠페인을 만들고 집행하고 성과를 봅니다. 결제 정보는 안 보이는 게 정상입니다.
페이스북 페이지콘텐츠 + 광고광고가 페이지 이름으로 나갑니다. 이게 빠지면 광고를 아예 못 만듭니다 (가장 흔한 누락).
인스타그램 계정콘텐츠 + 광고인스타 피드·릴스에 광고를 노출하고, 기존 게시물을 광고로 밀 때 필요합니다.
픽셀(데이터세트)관리구매·문의 같은 성과를 측정하고, 방문자에게 다시 광고합니다. 홈페이지가 없으면 나중에 해도 됩니다.

선택했으면 [공유] 또는 [저장]을 누릅니다. 여기까지가 맡기는 쪽이 할 일 전부입니다.

전체 관리 권한은 안 줘도 됩니다. 위 권한만으로 광고 운영은 전부 가능합니다. 계정 설정이나 결제를 대행사가 직접 만져야 하는 상황이 생기면 그때 해당 항목만 올려주면 됩니다. 처음부터 다 열지 않는 것이 정석입니다.

반대로 대행사가 먼저 요청할 수도 있습니다. 대행사 화면의 파트너 → 요청 보내기로 광고주에게 요청이 가고, 광고주는 알림에서 [승인]만 누르면 됩니다. 결과는 위 절차와 같습니다. 광고주가 화면을 헤맬 때 이 방법이 편합니다.

수락 전까지는 연결이 안 된 상태입니다. 광고주가 공유했는데 조용하다면 대개 수락을 안 눌렀거나 다른 비즈니스로 보낸 경우입니다.

STEP 4연결 확인 양쪽 함께

"공유했다 / 수락했다"까지는 아직 절반입니다. 실제로 광고를 만들 수 있는지를 눈으로 확인해야 연결 완료입니다.

  • 광고 관리자(adsmanager.facebook.com) 계정 목록에 해당 광고 계정이 보인다
  • 캠페인을 새로 만들 때 페이지와 인스타 계정이 선택 목록에 뜬다 — 여기서 안 뜨면 페이지 권한이 빠진 것
  • 이벤트 관리자에 픽셀이 보인다 (홈페이지가 있는 경우)
  • 광고 계정에 결제 수단(카드)이 등록되어 있다 — 없으면 첫 집행일에 반드시 멈춥니다
  • 광고 계정 결제 설정에 사업자등록번호가 들어가 있다 — 부가세 10% 면제 조건

캠페인은 초안까지만 만들어보고 저장하지 않으면 비용이 발생하지 않습니다. 테스트용으로 안심하고 확인하세요.

자산이 안 보일 때

파트너에게 넘길 수 있는 건 이미 금고(비즈니스) 안에 들어와 있는 자산뿐입니다. 공유 화면에 뭔가 안 보인다면 아직 금고에 안 넣은 것입니다. 설정 → 계정 메뉴에서 채웁니다.

안 보이는 것할 일시간
페이스북 페이지설정 → 계정 → 페이지 → [추가] → 페이지 이름 검색 → 추가3분
페이지를 검색해도 안 나옴다른 회사(이전 대행사) 비즈니스에 묶여 있는 상태입니다. 그쪽에 페이지 관리자 권한 이전을 요청해야 합니다.1~3일
인스타그램휴대폰 앱에서 프로페셔널(비즈니스) 계정으로 전환 → 페이지 연결 → PC에서 설정 → 계정 → 인스타그램 → 추가5~8분
광고 계정설정 → 계정 → 광고 계정 → 새로 만들기4분
픽셀설정 → 데이터 소스 → 데이터세트 → [추가] → 픽셀 만들기3분

광고 계정을 새로 만들 때 딱 두 가지만 조심 — 시간대는 Asia/Seoul, 통화는 KRW. 이 둘은 만들고 나면 바꿀 수 없습니다. 해외로 광고를 돌릴 계획이면 통화를 먼저 정하고 만드세요. 잘못 만들면 계정을 새로 파는 수밖에 없고, 그동안 쌓인 광고 학습이 초기화됩니다.

광고비 결제와 부가세

파트너로 연결돼도 광고비는 계정 주인의 결제 수단에서 나갑니다. 여기서 자주 사고가 납니다.

  • 카드는 광고주 담당자가 직접 입력합니다. 카드 번호를 메신저나 메일로 주고받지 않습니다. 대행사는 그 화면을 볼 필요도, 볼 수도 없습니다.
  • 예비 결제 수단을 한 장 더 등록해두세요. 메타는 카드 승인이 한 번만 실패해도 유예 → 미결제 → 광고 중단으로 이어집니다. 예비 카드가 있으면 자동으로 넘어가 멈추지 않습니다. 등록은 무료, 5분.
  • 사업자등록번호는 광고 계정마다 따로 넣어야 합니다. 비즈니스에 한 번 넣었다고 광고 계정에 자동으로 들어가지 않습니다. 넣지 않으면 광고비에 부가세 10%가 그대로 붙습니다. 소급 환급이 안 되니 지금 확인하세요.
  • 광고비를 대행사가 대신 결제하는 구조라면, 시작 전에 정산 방식과 한도를 문서로 정해두세요.
✓
확인 경로 — 광고 관리자 → 오른쪽 위 계정 선택 → 결제 설정 → 결제 수단 / 비즈니스 정보

막혔을 때 6가지

이런 증상진짜 원인해결
광고 계정은 보이는데 캠페인에서 페이지가 안 뜬다페이지 권한 누락 — 1위 사유페이지 자산을 추가로 공유
인스타 노출 위치를 못 고른다인스타가 개인 계정이거나 페이지와 연결 안 됨프로페셔널 전환 후 페이지 연결
공유했다는데 대행사 쪽에 아무것도 없다ID를 잘못 넣었거나 수락 대기 중ID 다시 확인 → 요청함 확인
"계정 사용 한도" 경고가 뜬다새 계정의 정상 동작그냥 진행. 집행하면서 자동으로 올라갑니다
광고가 갑자기 전부 멈췄다대개 권한이 아니라 결제 실패결제 설정에서 미결제 금액 확인 → 정산
소재가 계속 반려된다권한 문제가 아니라 광고 정책문구·이미지 수정. 담당자에게 검수 요청

대부분의 "안 돼요"는 권한 4종 중 하나가 빠진 것입니다. 막히면 먼저 2단계 표로 돌아가 네 가지가 다 공유됐는지부터 보세요.
