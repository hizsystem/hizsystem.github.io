처음부터 만들기 → HIZ 연결

비즈니스 관리자가 없을 때 대표님 노트북으로 같이 진행한다. 있는 단계는 건너뛴다 — 약 30분
시작 전 대표님 본인 페이스북 개인 계정이 필요하다. 없으면 facebook.com에서 실명으로 먼저 가입한다.

만드는 순서 끝낸 단계에 체크

1
비즈니스 포트폴리오 만들기 3분
business.facebook.com → [비즈니스 포트폴리오 만들기] → 이름 · 대표 실명 · 업무 이메일 → 메일 인증
이름은 사업자등록증 상호(한글) 그대로. 영문 소문자 · 아이디형은 반려된다
2
비즈니스 정보 입력 3분
설정 → 비즈니스 정보 → 법인명 · 주소 · 대표번호 · 사업자등록번호 · 웹사이트
사업자등록증을 옆에 두고 그대로 옮겨 적는다
3
페이스북 페이지 연결 3~10분
설정 → 계정 → 페이지 → [추가] → 기존 페이지 추가, 없으면 새 페이지 만들기 (이름 = 브랜드명)
검색이 안 되면 다른 회사 BM 소유. 그쪽에 이전 요청 (1~3일)
4
인스타그램 연결 5~8분
① 휴대폰 앱: 설정 → 프로페셔널 계정으로 전환 → 비즈니스
② PC: 설정 → 계정 → Instagram 계정 → [추가] → 로그인 → 페이지와 연결
순서가 중요하다. 앱에서 전환 먼저. 메뉴가 안 보이면 설정 검색창에 ‘프로페셔널’
5
광고 계정 만들기 4분
설정 → 계정 → 광고 계정 → [추가] → 새 광고 계정 만들기 → 사용 대상 ‘내 비즈니스’
시간대 서울 · 통화 KRW. 만든 뒤 못 바꾼다. 개인 계정의 옛 광고 계정은 끌어오지 말고 새로
6
결제 수단 등록 5분
광고 관리자 → 결제 설정 → 카드 추가 + 사업자등록번호 입력
카드는 대표님이 직접 입력. 첫 광고 게시 전까지만 하면 된다
7
픽셀 만들기 3분
설정 → 데이터 소스 → 데이터세트 → [추가] → 픽셀 → 사이트 주소 입력
사이트가 없으면 건너뛴다. 설치 코드는 나중에 사이트 관리자에게 전달
