STEP 5자사몰 부운영자 계정 (카페24)

픽셀과 전환 추적 코드를 심고, 어느 지점에서 이탈이 나는지 보기 위해 자사몰 접근이 필요합니다. 부운영자 계정 하나만 만들어 주시면 됩니다.

  • 디자인(HTML) 편집 권한 — 픽셀·전환API 코드 삽입에 필요합니다
  • 상품 / 주문 통계 조회 권한 — 어떤 상품이 어떤 경로로 팔리는지 확인
  • 앱(마이앱) 조회 권한 — 현재 연동된 마케팅 앱 상태 확인
  • (상품 구성을 새로 만들게 될 경우) 상품 등록 권한

💡 매출·정산 등 민감한 메뉴는 닫아두고 열어주셔도 됩니다. 위 네 가지만 열려 있으면 작업에 지장이 없습니다.

📌 쇼피파이 리뉴얼 일정도 알려주세요. 리뉴얼이 예정되어 있다면 픽셀 작업 시점을 맞춰야 데이터가 끊기지 않습니다.

STEP 6함께 보내주실 자료 2종

① 기존 광고 데이터

  • 최근 6개월 캠페인 성과 — 기간 / 지출 / 구매수 / 매출
  • 반응이 좋았던 소재 원본
  • 대행사에서 받으신 리포트

무엇이 되고 무엇이 안 됐는지를 먼저 보면, 같은 실험을 다시 하느라 쓰는 광고비를 줄일 수 있습니다.

② 소재로 쓸 수 있는 기존 영상

  • 인플루언서·체험단 영상, 유튜브 출연분 등 원본 파일 또는 링크
  • 해당 영상을 광고 소재로 2차 활용할 수 있는지 (사용 동의 범위)

이미 반응이 검증된 영상이 새로 만드는 것보다 빠르고 결과도 안정적입니다. 먼저 확보 가능한 범위를 파악해 두려 합니다.
